# OpenAmbience 1.0.0

Released October 22, 2026. This is the first stable release of OpenAmbience, a local, offline-capable ambient sound mixer with no account or backend requirement.

## Included in 1.0

- 29 built-in sounds: fifteen recordings, six generated textures and eight binaural presets, with up to six simultaneous layers and independent volume controls.
- Saved mixes, presets, search and category filtering, sleep timers, compatible system media controls and keyboard playback/navigation.
- Custom recording imports through the picker or drag and drop, plus device storage management and original recording downloads.
- Compatible HTTPS radio stations, with stream names/URLs retained in saved mixes and exports. Live radio still needs internet access.
- Versioned mix links and individual ZIP downloads, plus one ZIP for all saved mixes. ZIPs include referenced custom audio; shared recordings are included once. Collection imports let you choose mixes and preserve existing entries and playback.
- Offline app/library caching, explicit updates, install support where offered by the browser, and Nginx containers for Linux amd64/arm64.

## Upgrading

Use **Update & reload** in the app when offered. Existing saved mixes, uploaded recordings and version 1 exports remain compatible. There is no new browser-storage migration or playback change between 0.9.3 and 1.0.0. Browser data remains specific to its origin; use a mix ZIP to transfer to a different host/device.

For containers, `ghcr.io/vibeshibe/openambience:1.0.0` pins this release, `:1.0` follows this minor line and `:latest` follows stable builds from main. Existing Compose deployments using the default image can update with:

```sh
docker compose pull
docker compose up -d
```

## Stable compatibility

The 1.x line preserves documented version 1 mix links, individual/collection ZIP formats and built-in sound IDs. Compatible fixes use patch versions, additions use minor versions, and incompatible changes to this contract require a major version. See the [version policy](https://github.com/Vibeshibe/openambience/blob/v1.0.0/docs/versioning.md#stable-1x-compatibility-contract).

## Validation and known limits

The maintainer confirms weeks of satisfactory listening, working backups, offline cold starts, long mobile sessions with the sleep timer, media/lock-screen controls, 200% zoom, keyboard navigation and an initial Windows Narrator/Firefox check. These reports complement the existing CI and earlier recorded browser checks. This milestone does not claim a new comprehensive browser or accessibility audit.

Two Narrator announcement quirks remain documented: “padding” beneath the logo has not been reproduced, and the latest Play/Mute semantic cleanup needs user reconfirmation. Broader screen-reader coverage, actual storage pressure, installation checks across physical devices, interruption recovery and explicit locked-screen timer-expiry checks remain follow-up work.

Browser storage can be cleared or evicted; keep ZIP backups. Custom audio codec support depends on the browser, decoded mix audio is limited to 96 MiB, and large ZIP backups require sufficient browser memory. Radio supports direct CORS-enabled HTTPS streams, not station webpages or playlists. See the [validation record](https://github.com/Vibeshibe/openambience/blob/v1.0.0/docs/testing.md), [mix portability](https://github.com/Vibeshibe/openambience/blob/v1.0.0/docs/mix-portability.md) and [known limits](https://github.com/Vibeshibe/openambience/blob/v1.0.0/README.md#known-limits).

Stereo placement, optional sync, a larger catalog and selective offline downloads remain future work.
