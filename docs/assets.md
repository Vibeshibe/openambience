# Asset provenance

The first recording pack is bundled in `audio/`. The canonical [credit register](../audio/credits.json) records each creator, source title and URL, exact licence link, retrieval date, source and output SHA-256 checksums, file size, duration, and modifications. These credits are also accessible inside the app.

The recordings were acquired directly from the creators' public high-quality MP3 previews on Freesound, not from Ambiphone's hosted files. Sources use **CC0 1.0** or **CC BY 4.0**; no noncommercial-only recording is included. Preserve attribution when redistributing CC BY assets. Source-page licence assertions were checked during acquisition; the research register remains a broader list of candidates.

| Asset | Origin | License | Notes |
| --- | --- | --- | --- |
| Application code and styles | Original OpenAmbience implementation | MIT | No Ambiphone source copied |
| `icons/icon.svg` | Original geometric waveform mark | MIT | Vector artwork |

| `audio/*.mp3` | Creator recordings from Freesound | Individual CC0 / CC BY 4.0 | See the credit register; not covered by MIT |
| Imported audio | User-selected local files | Determined by the user’s source | Stored locally; never shipped or uploaded |
| Sound glyphs | Unicode characters rendered by system fonts | No bundled font asset | Appearance varies with installed fonts |

Ambiphone is referenced only for analysis and inspiration. Its name and linked content are not covered by this repository's license.

For each future recording, record the title, creator, original source URL, exact license/version, required attribution, retrieval date, modifications, duration, and checksum. A freely accessible download alone is insufficient provenance. Keep recording licenses separate from the code license.

## Preparation

The pack uses roughly 30-second excerpts at 44.1 kHz, stereo, MP3 128 kbit/s. Continuous recordings receive a 1.5-second wraparound crossfade; thunder receives an entrance/exit fade and a quiet interval during playback. FFmpeg loudness adjustment targets -25 LUFS, -5 dBTP, LRA 11. Preview re-encoding is lossy. No promise of studio fidelity or perfect perceptual loops is made.

`audio/credits.json` is the source of truth. After changing metadata, run `node scripts/build-catalog.js` to regenerate `js/catalog.js`; automated tests check metadata equality and all audio checksums. Add new recordings to the register to include them in the next offline cache installation, and bump the service-worker cache version.


## 0.5.0-alpha.1 additions

The new files are Rain on tent (30s), Evening birds (60s), and Train carriage (60s), adding 2,402,976 bytes (about 2.4 MB) to the offline pack. Morning birds reuses the existing `birds` file and ID. Train carriage includes the creator's requested attribution text in the register and in-app credits.

`scripts/prepare-expansion.py` checks source-preview SHA-256 hashes, takes the documented excerpts, converts to stereo 44.1 kHz, applies a 1.5-second wraparound crossfade, and encodes 128 kbit/s MP3. Its fixed gain targets -25 LUFS subject to a measured -5 dBTP cap, preserving natural dynamics. The tent recording is quieter because its transient peaks constrain the gain. Source recordings and FFmpeg are preparation inputs, not runtime dependencies. The script documents the download URLs and usage; run `node scripts/build-catalog.js` afterwards.

The source pages and licences were retrieved directly on 2026-10-05, including the evening-bird page that failed direct retrieval during the earlier research. Acquisition, encoding, decoded duration, signal levels, and offline playback were checked mechanically. Human listening for speech, handling noise, repetitive calls, and perceived loop seams remains pending.
